📱 Códigos QR para Votación

Genera códigos QR únicos para cada estudiante. Pueden escanear el código con la cámara de su dispositivo para votar rápidamente sin necesidad de escribir el código manual.

📋 Instrucciones

  • Haz clic en "Generar Códigos QR" para crear tokens únicos para todos los estudiantes
  • Imprime los códigos QR para que los estudiantes los utilicen
  • Los estudiantes pueden escanear su código con la cámara de su teléfono o tablet
  • El código QR contiene un token seguro único para cada estudiante

Haz clic en "Generar Códigos QR" para comenzar.
